# Authored ground interface scope

Third bounded read-only slice, after the compatibility and larger dressing boards.
`interfaces.json` binds the live scene, presentation owners, production builder,
approved layout, retained external recipes and forest/channel runtime acceptance.
All 39 scene terrain-texture assignments match their production-manifest bytes.
An explicit-reference scan covers 828 authored C#/scene/resource files, excluding
generated caches/build outputs, and binds their sorted path/hash corpus.

| Authored interface | Retained owner/evidence | Conditional future proof scope |
| --- | --- | --- |
| Broad ground | `Main.tscn` Ground uses repeated 256px quiet moss | A selected replacement or bounded patch needs named material, extent, phase, draw order and source bytes; no replacement is selected here |
| Woodland Clearing perimeter | Leaf litter plus retained straight and corner textures; `OpeningRegionWoodlandClearingSceneSource` configures their geometry | A selected new field at this boundary needs only its evidenced perimeter ports and world phases; preserve gate, openings, Forester and near-side exclusions |
| Paths/junctions | `GreyboxNavigation` owns route presentation and named promoted textures | A selected ground change beneath a specific route requires external alpha-edge composition against that exact route; generic earth/gravel connectors do not establish path compatibility |

| Stream/banks/channel | Native Stream nodes plus five separately promoted channel sprites | Any selected adjacent ground proof must retain native UVs, regions, caps, crossing, three-node shader scope, and accepted channel transitions; no bank/water repainting |
| Closed-forest path | Named closed-side promotion, retained gate/geometry and runtime acceptance | Any selected ground underneath this route needs its exact source-matched external composition; near-side Clearing remains untextured |

The retained production builder's `make_leaf_litter_transition` and connector
functions take quiet-moss and leaf-litter sources. They establish an existing
legacy/legacy interface; they do not establish connectors for the six new fields.
The accepted new-field transition families separately bind earth/gravel and
meadow/soil. The current scene's assignments and source scan select no explicit
new-field use. This does not prove that arbitrary dynamically synthesized resource
paths could never load one, and this audit makes no GPU/runtime validation claim.

No required new connector follows from the evidence. Terrain remains open because
production placement, appropriate dressing density, imports, usability and owner
terrain-completeness acceptance have not been established. Do not treat colour
delta rankings as a geography plan or generate twelve transition families.

The next boundary is owner selection of a new field and intended interface or
composition, or an explicit request for a placement proposal. Once selected, the
next slice is **one separate external source-matched feasibility composition** for
that exact use: bind the existing paint and recipe, retain native periods/phases,
show scale and edge evidence, preserve failures and state any concrete connector
need. No artwork authoring or runtime promotion is implied by that selection;
those remain scoped separately. Until selection, preserve the frozen packages
and do not invent new material geography merely to continue work.

Reproduce with `interfaces.py`; verify without writing with `interfaces.py --check`.
The report binds the preceding audit JSON files, while their own checks verify the
board pixels and complete frozen inputs. Run all three package checks together.

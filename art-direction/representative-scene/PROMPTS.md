# Representative-scene generation prompts

All four previews used Codex's built-in image-generation tool with transparency disabled. Each call
used `reference/greybox-camera-reference.png` as Image 1. The text below is the exact prompt supplied
for each call.

## Direction A — storybook gouache

```text
Use case: stylized-concept
Asset type: preview-only game art-direction concept
Primary request: Create Direction A, a painterly storybook visual interpretation of the same small representative Allrpcs scene shown by the reference image.
Input images: Image 1 is a same-project greybox camera-and-scale reference only. Preserve its readable 16:9 gameplay framing, approximate object scale, and top/bottom UI layering, but replace the greybox content with the exact reduced scene below.
Scene/backdrop: a compact rural village-edge clearing crossed by one curved dirt path, with exactly one small timber-and-plaster healer's cottage, two modest herb beds beside it, and restrained edge vegetation.
Subject: exactly two full-body human characters at gameplay scale, the Seeker in a teal travel cloak and the Healer in an ochre apron; exactly one clearly interactable waist-high stone herb-preparation table near the herb beds, highlighted by shape and a subtle golden focus ring rather than colour alone.
Style/medium: painterly storybook game concept, matte gouache textures, simplified hand-painted forms, gentle uneven ink outlines, readable silhouettes, no photorealism.
Composition/framing: 16:9 landscape gameplay screenshot, high oblique three-quarter top-down camera comparable to the greybox reference, building footprint large enough to enter, characters small but expressive, dialogue UI across the bottom quarter, slim translucent status panel at upper left.
Lighting/mood: warm late-afternoon side light, welcoming but investigative, long soft shadows, faint dust and leaf motes.
Color palette: moss green, warm ochre, cream plaster, weathered brown, teal character accent; preserve value contrast for colour-vision-independent legibility.
Materials/textures: visible brush grain, worn timber, packed earth, soft foliage clusters.
Text (verbatim): dialogue panel labels "SAY AS SEEKER", "HEALER", and "SUBMIT"; no other readable text.
Constraints: preview only; exactly one building, exactly two characters, plants, exactly one interactable object; keep all subjects unobscured; UI must read as practical game UI rather than poster typography; preserve navigation clarity; no logos, trademarks, watermark, map, inventory, extra props, extra characters, combat, dramatic cinematic close-up, or production-asset sheet.
Avoid: generic fantasy castle imagery, excessive bloom, tiny characters, colour-only interaction cues, illegible decorative text.
```
